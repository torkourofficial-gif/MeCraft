# MeCraft (Minecraft para Java ME)

MeCraft es un port de Minecraft para telefonos java con **MIDP 2.0, CLDC 1.1 y M3G (JSR-184)**. Toma como referencia el codigo de Minecraft Indev 20100223 y Alpha 1.2.6

Enserio, MUCHAS gracias al equipo de eaglerports, ya que gracias a este pude usar codigo de Indev 20100223 y de Alpha 1.2.6
