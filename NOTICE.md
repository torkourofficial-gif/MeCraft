MeCraft adapta a MIDP/M3G varias reglas consultadas en **Minecraft Indev 20100223**, incluidas las medidas del jugador, la fuerza de rotura por dureza, las restricciones de recolección y el comportamiento de los fragmentos. La referencia técnica es [EaglerPorts/in-20100223](https://github.com/EaglerPorts/in-20100223), cuyo README atribuye el proyecto a [Colbster937](https://github.com/colbster937) y permite forks con atribución. Esta adaptación usa estructuras acotadas para Java ME y no incluye clases copiadas literalmente del cliente original.

Los PNG de este repositorio se conservan sin modificar. Su titularidad y licencia corresponden a sus autores originales; este aviso no concede derechos adicionales sobre esos assets.

El código de MeCraft en `src/mecraft/` es una implementación original del demake para MIDP/M3G. Confirma los derechos/licencias de las texturas antes de redistribuir un `.jar` que las incluya.
